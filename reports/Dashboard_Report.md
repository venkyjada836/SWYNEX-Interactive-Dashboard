\# Titanic Survival Analysis – Dashboard Report



\## 1. Project Overview



This project focuses on building an interactive dashboard using Microsoft Power BI Desktop to analyze passenger survival patterns from the Titanic dataset.



The dashboard provides KPI cards, visualizations, and interactive slicers to help users explore the data.



\## 2. Dataset Information



\- Dataset: Titanic

\- Total Records: 784

\- Total Columns: 15

\- Missing Values: 0 after cleaning

\- Data Source: Cleaned dataset from SWYNEX Task 1 and Task 2



The analysis uses the cleaned dataset, which excludes 107 duplicate-looking records from the original dataset. Some of those records could represent distinct passengers with identical recorded attributes.



\## 3. Tools Used



\- Microsoft Power BI Desktop

\- DAX

\- Power BI Data Modeling

\- Interactive Data Visualization



\## 4. Dashboard KPIs



| KPI | Value |

|---|---|

| Total Passengers | 784 |

| Total Survivors | 323 |

| Non-Survivors | 461 |

| Survival Rate | 41.20% |



\## 5. Dashboard Visualizations



\*\*Survival by Gender:\*\* Compares survival rates between female and male passengers.



\*\*Survival by Passenger Class:\*\* Analyzes survival rates across first, second, and third class.



\*\*Survival by Age Group:\*\* Compares survival patterns among children, teenagers, young adults, adults, and seniors.



\## 6. Interactive Filters



The dashboard includes three slicers:



\- Gender

\- Passenger Class

\- Embarkation Town



These filters allow users to explore different passenger groups dynamically.



\## 7. Key Insights



1\. Female passengers had a 74.06% survival rate, compared with 21.59% for male passengers.

2\. First-class passengers had a 63.08% survival rate, while third-class passengers had a 25.68% survival rate.

3\. Children had a 57.35% survival rate, compared with 22.73% for seniors.

4\. Overall, 323 of 784 passengers survived, giving a survival rate of 41.20%.

5\. Cherbourg had the highest survival rate by embarkation town at 58.06%.



These findings describe associations within the cleaned dataset and do not establish causation.



\## 8. Conclusion



The interactive Power BI dashboard provides a visual overview of Titanic passenger survival patterns. It demonstrates skills in data visualization, DAX calculations, dashboard design, and interactive reporting.
