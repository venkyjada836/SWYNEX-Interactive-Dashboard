\# SWYNEX – Interactive Dashboard



\## Project Overview

Developed an interactive Titanic Survival Analysis Dashboard using Microsoft Power BI Desktop. The dashboard presents passenger survival patterns through KPIs, visualizations, and interactive filters.



\## Objectives

\- Build an interactive business intelligence dashboard.

\- Analyze passenger survival patterns.

\- Present key performance indicators.

\- Use slicers to explore passenger demographics.



\## Dataset

\- Dataset: Titanic cleaned dataset

\- Records: 784 passengers

\- Columns: 15

\- Missing values in the cleaned dataset: 0



\## Tools and Technologies

\- Microsoft Power BI Desktop

\- Power Query

\- DAX (Data Analysis Expressions)

\- Data visualization and interactive slicers



\## Dashboard Features



\### KPI Cards

\- Total Passengers: 784

\- Total Survivors: 323

\- Survival Rate: 41.20%

\- Non-Survivors: 461



\### Visualizations

1\. Survival Rate by Gender

2\. Survival Rate by Passenger Class

3\. Survival Rate by Age Group



\### Interactive Filters

\- Gender

\- Passenger Class

\- Embarkation Town



\## Key Insights

1\. Female passengers had a 74.06% survival rate, compared with 21.59% for male passengers.

2\. First-class passengers had a 63.08% survival rate, compared with 25.68% for third-class passengers.

3\. Children had a 57.35% survival rate, while senior passengers had a 22.73% survival rate.

4\. Overall survival rate was 41.20%.

5\. Cherbourg had the highest survival rate among the three embarkation towns at 58.06%.
